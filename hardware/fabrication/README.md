# Fabrication Outputs

`gerbers_final/` contains the final fabrication files supplied with the project.

Before sending them to a PCB manufacturer, open the Gerbers in an independent viewer and verify:

- board outline / Edge.Cuts
- front and back copper
- solder mask
- silkscreen
- paste layers if required by the assembly process
- PTH and NPTH drill files
- drill map
- intended board revision

The Gerber ZIP in this folder is a convenient packaged output. The individual files are retained so the layer set is directly inspectable in the repository.
